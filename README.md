# 🚀 Premium MERN Stack Portfolio

A high-performance, visually stunning portfolio website built with **React.js**, **Tailwind CSS**, and **Framer Motion**. Featuring a premium dark-mode UI, smooth scroll animations, and a fully responsive layout.

## ✨ Features

- **Modern Dark UI:** Clean `#0a0a0c` background with vibrant purple accents.
- **Glassmorphism:** Elegant backdrop-blur effects on the navbar and cards.
- **Advanced Animations:** Smooth entrance and hover animations using Framer Motion.
- **Dynamic Projects Section:** Features pagination and interactive project cards.
- **Auto-Active Navigation:** Navbar links automatically update based on scroll position.
- **Fully Responsive:** Optimized for Mobile, Tablet, and Desktop screens.

## 🛠️ Tech Stack

- **Frontend:** React.js, Tailwind CSS, Framer Motion
- **Icons:** React Icons (Ri, Fa, Bi)
- **State Management:** React Hooks (useState, useEffect)
- **Build Tool:** Vite
- **Deployment:** Netlify
